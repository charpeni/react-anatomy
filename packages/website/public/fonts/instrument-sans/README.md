# Instrument Sans

The website uses Instrument Sans as its sans-serif typeface. These unmodified variable WOFF2 files provide weights 400–700 in normal and italic styles, with Latin and Latin Extended subsets.

- Design and source: [Instrument Sans](https://github.com/Instrument/instrument-sans).
- Distribution: `@fontsource-variable/instrument-sans@5.3.0`, from [the pinned npm archive](https://registry.npmjs.org/@fontsource-variable/instrument-sans/-/instrument-sans-5.3.0.tgz).
- License: [SIL Open Font License 1.1](OFL.txt), included unchanged.
- Archive integrity: `sha512-u4gKbDBTNFGkg997tfQn3eHOhHuquWUFTRT/rwzuKtrxX5P2ekfs2x+LgBPP4P32+cC+vUwF1Cr+IdRoPQbrGw==`, verified before extraction.

The CSS in `src/styles/fonts.css` retains the distribution's Unicode ranges. All font requests use this site's origin. The normal Latin face is preloaded; italic and extended glyphs load as needed. No external font stylesheet or font service is used.
